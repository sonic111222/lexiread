## 正文

📖 最近在做一个英语精读小工具，起因很具体：

读阅读题时，我总在「文章、词典、题目」之间来回切窗口。
查完一个词，回文又忘了它在句子里怎么用；
生词收藏了一堆，真正复习的却没几个。

✨ 所以我把这条流程做成了一件事：

📤 上传题图 → 本机 OCR 校对 → 📖 精读排版 → 点词学习 → ✅ 做题复盘 → ⭐ 收藏复习

💡 现在它能做这些：

1. 上传阅读 / 完形填空的图片，用 Windows 本机 OCR 识别，图片不上传
2. 自动把文章、题目、选项排成一张阅读页，识别错了可以先改
3. 点任意单词，看音标、中文释义、词形变化，还有它在原文里的那一句
4. 题目先自己选，再用定位词和原文线索复盘，不直接替你选
5. 生词本保存在本机，可以搜索、标记掌握、抽认卡复习、导出 CSV
6. AI 是可选功能：可以生成译文、答案依据、长难句和语法点；不配置 Key 也能用本地功能

它不是拍照直接出作业答案的工具，也不是承诺效果的课程。
我更想把它做成一个能安静读透一篇文章的桌面工具。

💻 目前只支持 Windows 10/11。
📌 源码公开，个人学习、研究、学校/公益等非商业使用免费；商业使用需要单独授权。

## 置顶评论

补充一下边界：

- 目前只有 Windows，Mac / iPad 暂时不行
- 图片只在本机 OCR；AI 需要你自己的 API Key
- 示例文章是原创的，没有使用真题原文
- 免费非商业使用，商业使用需要单独授权 🙏

## 第二条评论

如果没有 AI Key，也可以正常用：本地 OCR、离线词典、点词和生词本都不依赖 AI。  
AI 更像是“精讲老师”，不是启动应用的前提。
