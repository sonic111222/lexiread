LexiRead · 精读工坊 — Windows 便携版
====================================

1. 把整个文件夹解压到“文档”“桌面”或其他可写目录。
2. 双击 LexiRead.exe。
3. 程序会自动在浏览器打开 http://127.0.0.1:5057
   如果端口被占用，请查看黑色启动窗口里打印的地址。
4. 使用期间不要关闭启动窗口。结束时直接关闭窗口即可。

数据位置
--------
程序会在 exe 同目录创建 data 文件夹：
- data/lexiread.db   生词本、设置、词典缓存
- data/uploads/      你上传的题目图片

删除 data 文件夹会重置全部本地数据，建议先导出 CSV。

隐私
----
图片只在本机用 Windows OCR 识别。
离线查词不联网；本地词库没有的词才会查询在线 Wiktionary。
只有你主动点击“AI 精讲”时，文本才会发送给你配置的模型。
项目没有账号、广告 SDK 或遥测。

OCR 提示
--------
在 Windows“设置 → 时间和语言 → 语言”中安装 English 语言包，
英文识别会更稳定。识别结果进入精读前可以先编辑校对。

AI（可选）
----------
设置 → AI 精讲连接，填写任意 OpenAI 兼容接口的 Base URL、模型和 Key。
仓库不包含任何 API Key。没有 Key 时，本地 OCR、点词和生词本仍可使用。

安全提示
--------
这是未签名的公开源码构建，Windows SmartScreen 可能提示风险。
请只从项目官方 Releases 下载，并核对发布页提供的 SHA256。
